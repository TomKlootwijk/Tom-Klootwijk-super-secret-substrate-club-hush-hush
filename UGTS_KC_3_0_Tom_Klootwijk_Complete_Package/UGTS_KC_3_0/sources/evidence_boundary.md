# Evidence boundary

The report and catalog use these labels:

- `SOURCE` / source-normalized: directly extracted or technically normalized from the supplied reports and their internal source register.
- `ENGINEERING`: added to make the system mathematically or operationally complete within a bounded scope.
- `IMPLEMENTED + TESTED`: exercised by the bundled unit tests.
- `PROTOTYPE + TESTED`: implemented as a bounded reference with known restrictions.
- `SPECIFIED`: contract or architecture is defined, but a complete production implementation is not claimed.
- `REQUIRES MEASUREMENT`: a physical or performance claim needs a named device and full measurement context.

Source language, engineering interpretation and measured evidence must not be merged into a single unqualified claim.
