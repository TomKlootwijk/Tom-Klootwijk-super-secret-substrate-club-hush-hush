# Package notice

This package distinguishes three evidence layers:

1. **Source-normalized baseline (M001-M197).** Extracted or normalized from the two supplied UGTS reports and their registered source corpus.
2. **UGTS-KC 2.0 engineering expansion (M198-M257).** Pattern, field, topology, kinematic and bounded-dynamics additions.
3. **UGTS-KC 3.0 engineering expansion (M258-M360).** New engineering mechanisms implemented or specified in this package.

The engineering layers are not represented as source quotations. They are technical extensions selected to preserve the source architecture and make the substrate more explicit, testable and reproducible.

No claim is made that this package establishes physical-GPU speed, FPGA/ASIC performance, optical advantage, universal constant-time event solving, zero memory/energy/latency, exact arbitrary-field roots, physical non-orientable self-assembly or complete state in one bit.
