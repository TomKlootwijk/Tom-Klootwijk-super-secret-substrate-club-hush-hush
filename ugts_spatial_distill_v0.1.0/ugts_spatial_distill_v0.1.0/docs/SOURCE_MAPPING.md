# Source Mapping and Evidence Boundary

## Source-derived substrate terms

The uploaded UGTS material directly supports the following conceptual contract:

- query-first state/event authority rather than mandatory rendering;
- local radial/angular support;
- typed compatibility;
- finite relation/SDF guard;
- verified event and transition;
- route, lineage and ordered novelty;
- coordinates distinct from durable identity;
- seed/grammar replay for closed dynamics and storage of exogenous events;
- packed G64/E32 and G32/E16 profiles with an error-margin requirement.

The original markdown also motivates raw integer bit streams, log-polar
addressing, parity routes, explicit gluing maps and GPU-side decode.

## Engineering translations in this project

These are not stated as source-proved mechanisms:

- HGT-style typed attention;
- TGN-style temporal memory;
- H3 or Morton broad-phase indexing;
- Qwen embedding teacher;
- GeoNames/OSM adapters;
- distillation losses and threshold calibration;
- the synthetic Flevoland task;
- benchmark rates produced by this package.

## Unsupported inference boundary

The implementation does not infer:

- that a graph neural network is required for every geospatial workload;
- that one bit represents complete state;
- that packed data is automatically faster;
- that a topological routing abstraction changes physical VRAM topology;
- that a software validation result proves physical-device advantage.
