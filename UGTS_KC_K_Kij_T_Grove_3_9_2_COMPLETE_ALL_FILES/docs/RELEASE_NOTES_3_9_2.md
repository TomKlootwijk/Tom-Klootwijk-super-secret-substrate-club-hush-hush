# Release Notes — 3.9.2

**K-Kij-T / Grove**

3.9.2 is a native Android upgrade of 3.9.1 focused on game-feel and Mali-G720 MC7 quality. It adds a real Grove juice controller, GLES post composite, shockwave/flash/bloom response, device tuning, KC3D392 assets, and a native-only Android target.

No HTML5 runtime is part of Grove. PCG remains a future TODO.
