## UGTS Spatial KD cone-gate provenance

The portable `query.nearest_in_cone` radial/angular gate is adapted from the
GSP4 engineering implementation in the sibling `gsp4_spatial_kd_v0.5.0`
repository. UGTS-KC keeps the source-aligned normalized-direction/cosine gate,
including its clamped small-distance denominator, while replacing geographic
coordinates, PyTorch tensors and runtime trigonometry with an explicit
world-space axis and fully specified binary32 rounding so desktop, browser and
Android builds can share the result. Origin rotation and scale are not inputs.

## UGTS GPU Native bounded-event provenance

The portable visual-graph message queue adapts the bounded FIFO, canonical
ordering and explicit overflow-budget mechanisms documented by the sibling
UGTS GPU Native Addendum package. UGTS-KC applies those engineering mechanisms
to ordinary game messages; it does not claim that a game message is physical
evidence or a verified scientific event.
