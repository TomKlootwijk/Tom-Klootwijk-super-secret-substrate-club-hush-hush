# Changelog

## 3.6.3 - SARA

- Added the `sara363.*` Seed-Address Referential Algebra namespace.
- Added BIP39 entropy/checksum/11-bit word-cell mapping and wordlist commitment.
- Added public-test-vector BIP32/BIP84 derivation and Bech32/Bech32m codecs.
- Added a public-only certificate and explicit secret nonserialization rules.
- Added a public decode fixture for the requester-supplied `bc1q...` address.
- Added an authorization gate that rejects third-party key search, mnemonic enumeration, passphrase spraying, signing, broadcasting and funds transfer.
- Added keyspace/time metrics without candidate generation.
- Added 42 SARA tests while retaining all 153 earlier tests (195 total).
- Added JSON Schema, literal substrate definitions, catalogs, figures, formal report and checksum manifest.

## 3.6.2 - SCLP
