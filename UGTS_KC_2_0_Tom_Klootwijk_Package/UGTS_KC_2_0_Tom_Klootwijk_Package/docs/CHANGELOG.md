# Changelog

## UGTS-KC 2.0 - 2026-08-16

- Preserves the query-first relation/event architecture of UGTS-0 and UGTS-GN 1.1.
- Retains the 197-mechanism baseline as a frozen source-derived/normalized catalog.
- Adds M198-M257 as 60 clearly labeled engineering additions.
- Adds a pattern grammar for superellipses, trochoids, splines, periodic fields and swept surfaces.
- Adds topology descriptors: winding, covering lifts, homotopy signatures, braid words, cell complexes and chart cocycles.
- Adds SE(2)/SE(3) twist calculus, quaternion/screw interpolation, moving frames, arc length, limit-aware timing and articulated kinematics.
- Adds bounded dynamic operators: symplectic integration, damped modes, graph diffusion, reaction-diffusion, hybrid automata and event degeneracy resolution.
- Adds an executable standard-library reference implementation and validation suite.
- Does not promote speculative physical or universal performance claims.
