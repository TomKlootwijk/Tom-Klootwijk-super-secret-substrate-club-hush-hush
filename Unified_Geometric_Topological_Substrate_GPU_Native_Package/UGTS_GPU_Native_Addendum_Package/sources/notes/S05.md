# S05 — Bounded physical waveguide endpoint

## Source-derived mechanisms
A local radial-angular input is shaped by a controllable liquid interface, coupled into a compatible waveguide mode, observed by detectors and declared as a Bounded Compatibility Event only at a measured guard crossing. The source supplies a benchmark vector: verified event rate, route efficiency, events per joule, support and compatibility pruning, median/tail latency, miss/false-event probability and drift.

## Technical normalization
Maxwell equations govern optical fields; coupled-mode theory governs amplitudes; Young–Laplace and fluid mechanics govern the liquid interface; digital event logic governs declaration, confidence and lineage. The physical endpoint is not required for the Vulkan substrate, but it shares the same ABI: support → compatibility → guard → commit.
