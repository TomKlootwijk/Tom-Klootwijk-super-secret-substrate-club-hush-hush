# S02 — Zero-based timeline, split oval and overlap geometry

## Source-derived mechanisms
- Difference between an offset and an ordinal: index 35 is the 36th item in a zero-based array.
- A split zero-centered oval under torque becomes an antisymmetric wave with a zero-displacement hinge.
- A `2π` loop can be unrolled as two `π` arches; the source proposes a 1:1 phase balance.
- Two folded phi/D bodies share a stem and create a slightly overlapping lens.
- The lens is interpreted three ways: constructive interference, tolerance/phase-slip buffer, and information-theoretic intersection `A∩B`.

## Technical normalization
Zero-based indexing changes labels, not arithmetic. The split-oval and double-arch constructions are retained as kinematic parameterizations. The overlap lens becomes an explicit intersection region with measurable area, phase or confidence—not a mystical welding point.
