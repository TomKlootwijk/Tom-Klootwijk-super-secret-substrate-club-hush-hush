# S04 — Projection and output operators

## Source-derived mechanisms
- Cartesian-to-log-polar addressing: `ρ = ln(r)`, `θ = atan2(y,x)`.
- One-bit sector mask before SDF/CSG evaluation.
- SDF union/intersection/subtraction and zero-isosurface boundary.
- “Feynman vector” coverage translated as deterministic complex phasor accumulation or multisample coverage—not quantum simulation.
- SDF gradient for edge orientation.
- One-bit temporal PDM, anisotropic delta-sigma modulation, chromatic log-radius offsets, seeded jitter, log-polar screening and dot-gain compensation.

## Technical normalization
These are downstream output paths. They may visualize or actuate substrate results, but they do not define authoritative state. “Zero cost,” “perfect refraction” and “eliminates aliasing” are replaced with measured instruction, bandwidth and error budgets.
