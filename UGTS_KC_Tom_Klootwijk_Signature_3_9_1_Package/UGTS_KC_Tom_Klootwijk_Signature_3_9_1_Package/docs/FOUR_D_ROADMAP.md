# 4D Roadmap

4D is deliberately a TODO, not a hidden feature claim.

1. Select spacetime gameplay or four-spatial-dimensional geometry as the first experiment.
2. Define metric, orientation, units, projection/slicing, collision and determinism contracts.
3. Add dependency-free `Vec4`, bivector/rotor or SO(4) rotation tests without altering 3D state.
4. Build a CPU projection oracle and deterministic fixtures.
5. Add an optional renderer path only after projection semantics pass tests.
6. Measure practical game-design value and keep explicit kill criteria.

The earliest candidate schema is reserved for a post-3.9.1 experimental namespace. M450 is not
allocated by this release.
