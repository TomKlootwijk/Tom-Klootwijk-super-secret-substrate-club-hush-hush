# Release Notes — UGTS-KC 3.9.1 Tom Klootwijk Signature Edition

3.9.1 is an additive mobile/3D upgrade over the 3.9 KC Elizabeth release.

## Added

- a validated, serializable mobile-3D project model;
- primitive cube, plane, pyramid and UV-sphere meshes;
- deterministic 3D arcade movement, gravity, floor/bounds, sphere-proxy contacts,
  collectibles, hazards, goals, snapshots and hashes;
- capability-scored Android profiles, led by a POCO X7 Pro 12 GB/120 Hz signature tier;
- ordered quality tiers and FPS/thermal downgrade/recovery controllers;
- the compact `KC3D391` native scene-pack compiler and structural inspector;
- a dependency-free Android `NativeActivity` source project in C++20;
- EGL/OpenGL ES 3.0 rendering, depth/culling, dynamic-resolution framebuffer,
  touch/gamepad/keyboard input and requested high-refresh presentation;
- a 66-node playable signature arena example;
- glTF export through the retained 3.0 interchange layer;
- CLI commands for 3D creation, validation, simulation, packing, glTF and Android source builds;
- mechanisms M390–M449, taking the extended engineering catalog to M449.

## Retained

All 3.9 2D vector art, browser game, HTML5 export and original 2.0/3.0 APIs remain present.

## Not included

No APK or AAB is represented as built or device-tested in this archive. The Android source requires
the documented Android SDK/NDK/Gradle toolchain and app signing. Vulkan and 4D remain future work.
