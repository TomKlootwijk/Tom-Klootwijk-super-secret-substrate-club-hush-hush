# Release Notes - 3.9.0 KC Elizabeth

KC Elizabeth turns the supplied 3.0 graphics/reference package into an end-to-end vector-game workflow. The release is designed around a single editable JSON project that can be validated and simulated in Python and compiled into a browser-playable game without external runtime dependencies.

The included vertical slice, **Elizabeth's Vector Garden**, demonstrates vector gradients, camera following, keyboard/gamepad/touch input, dash movement, static and moving obstacles, collision response, collectibles, hazards, health, scoring, win/lose states, particles, procedural sound/music, persistence and diagnostics.

The release adds 60 cataloged mechanisms, 108 tests and 11 new Python modules while retaining all previous tests and source areas. It is intentionally a pragmatic reference stack: small enough to understand and modify, but complete enough to create and distribute compact 2D browser games.
