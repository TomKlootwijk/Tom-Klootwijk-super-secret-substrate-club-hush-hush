# Substrate alignment

The app keeps the recurring UGTS authority sequence:

```text
capture + measured observation
  -> local support
  -> semantic/topological compatibility
  -> guard/error/uncertainty classification
  -> verified proposal
  -> one deterministic map/ledger commit
  -> pre/post hashes, lineage and replay/export
```

UGTS-KC 2.0 supplies typed geometry, kinematics, uncertainty and event semantics. KC Two Hands 3.0 supplies stable identity, proposal/commit separation and pre/post replay discipline. UGTS-KC 3.6 supplies content-addressed definitions and explicit operation order. SCLP 3.6.2 supplies finite packing and error boundaries. KC Atlas 3.9.3 supplies the spatial-evidence bridge. The 4.1 report supplies the seed/evidence distinction, KSEED framing, verifier gate order, synthetic isolation and native target.

The seed does not recreate unstored observations. Packed records remain valid only under declared quantization/error policy. Camera, IMU, feature, model and native callbacks propose; the platform-independent verifier and ledger commit.
