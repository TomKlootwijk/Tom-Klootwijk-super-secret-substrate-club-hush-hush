# POCO X7 Pro 12 GB profile

The source profile targets `arm64-v8a`, Camera2 `YUV_420_888`, 640-pixel analysis long edge, maxImages=2, 1,100 features, 260,000 voxels and thermal analysis tiers of 15/10/6 fps. The arm64 seed library is built with NDK 29.0.14206865 and CMake 3.22.1.

These are requested/source parameters, not measured device results. The build/deploy operator must record actual phone model, OS build, GPU, camera ID, YUV resolution, cadence, latency, memory, thermal behavior and battery use.
