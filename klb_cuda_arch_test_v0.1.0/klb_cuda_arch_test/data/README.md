# Data

## Included

`procedural_65536.klb` contains 65,536 points generated by this project's parity-bifurcated L-system generator.

Validated properties at generation time:

```text
records                 : 65536
padded records          : 65536
record width            : 37 bits
payload bytes           : 303104
container bytes         : 303240
payload bytes/point     : 4.625000
container ratio/float3  : 2.593431x
RMS position error      : 0.001539 (0.085155% of radius)
max position error      : 0.002969 (0.164305% of radius)
payload FNV-1a          : 0x42067a98d1069530
```

Regenerate it with:

```bash
klb_pack generate data/procedural_65536.klb --points 65536
```

Decode a PLY preview only when needed:

```bash
klb_pack inspect data/procedural_65536.klb --decoded procedural_preview.ply
```
